# AI Agent Instructions - ChatPulse

1. **Git Policy:** Do NOT push changes to git unless the user explicitly requests it. You may ask if the user wants changes pushed, but do not push autonomously.
2. **Documentation maintenance:** Make it a habit to update `AI_AGENT_INSTRUCTIONS.md` and `VERSIONS.md` inside the `doc` folder after making major updates.
3. **README maintenance:** Always synchronize the `README.md` to cleanly state the current project capabilities after significant feature additions.
4. **UI Philosophy:** ChatPulse utilizes premium CSS (glassmorphism, clean box-shadows, buttery iOS-style easing animations without heavy frameworks).
5. **Mobile Design:** Ensure any new UI handles mobile safe-areas gracefully, avoids iOS zoom behavior on input, and provides adequate space above keyboards.
