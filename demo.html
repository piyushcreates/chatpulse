Webhook Configuration

The widget is currently configured to send messages to:

https://your-webhook-endpoint.com/chat
Note: Make sure your webhook is configured to:
  • Accept POST requests with JSON payload
  • Enable CORS (Access-Control-Allow-Origin: *)
  • Return JSON response with a "message" field
  • Use synchronous response mode

Expected Payload

The widget sends this JSON structure:

{ "message": "User's message text", "sessionId": "session_1234567890_abc123", "timestamp": "2026-02-02T21:35:36+05:30" }

Expected Response

Your webhook should return:

{ "message": "Bot's response text (supports markdown)" }

Embedding on Your Website

To embed this widget on any website, add these files:

<link rel="stylesheet" href="widget.css"> <!-- Include widget HTML or use embed.js --> <script src="widget.js"></script>
